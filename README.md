# Produktsuche – Business-Projekt

Wir suchen zu zweit ein Produkt für ein gemeinsames Business. Beide arbeiten mit ihrem eigenen Claude-Account über Amoeba im selben Projektordner.

## Ordner
- `CLAUDE.md` – Regeln für beide Claudes (zuerst lesen)
- `00-ausgangslage.md` – Budget, Zeit, Ziele (von euch auszufüllen)
- `01-kriterien.md` – Bewertungsraster für Produkte
- `02-kandidaten.md` – Tabelle aller Produktideen mit Punkten
- `03-aufgaben.md` – Wer macht was (Aufgabenteilung)
- `recherche/` – Notizen pro Produkt, eine Datei je Idee (`produktname.md`)

## Ablauf
1. Beide füllen `00-ausgangslage.md` aus (5 Minuten).
2. Ideen sammeln, jede kommt in `02-kandidaten.md`.
3. Jede Idee wird nach `01-kriterien.md` bewertet.
4. Die Top 3 werden in `recherche/` vertieft (Konkurrenz, Lieferant, Marge).
5. Gemeinsame Entscheidung, Ergebnis unten festhalten.
